# Project rules

## Task orchestration

Pick the model and effort for each task or subagent by how complex the task is:

| Task | Model | Effort |
| --- | --- | --- |
| Complex (architecture, multi-file changes, hard debugging) | Opus | medium |
| Medium (a focused feature or fix in a few files) | Sonnet | medium |
| Simple (lookups, small edits, mechanical changes) | Haiku | max |
